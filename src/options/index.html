Privacy mode

Strict privacy proxies public destinations, blocks local destinations and removes automatic captcha exemptions. Compatibility allows Iran-list, custom and local direct connections, including during proxy failure.

Updates change which sites connect directly. Their checksum does not independently authenticate the publisher. Each candidate requires manual review and approval. Off by default.

Separate your browsing identity

Use a dedicated browser profile for private browsing. Switching proxies does not clear cookies, logins, IndexedDB or service workers. This extension does not isolate accounts or erase site data.

Startup scripts, new iframe realms and unsupported workers can still reveal native values. Incognito spoofing requires enabling the extension there. Use an OS firewall or VPN kill switch for enforcement outside browser controls.

Stealth mode

Off by default. Makes every patched function copy the exact shape of the native one, and removes this extension's frames from the stack of errors that pass through a patch.

Google Flow unlock

On by default. Not a privacy shield: it works around a regional block of Google Flow. On Flow pages only, it rewrites the country check in Flow's own answers and sends the tab back to Flow if it lands on the "unsupported country" page. It reads a private Google format, so it can stop working when Google changes it.
